# Handoff

Пишет **файл** с состоянием работы, чтобы новая сессия стартовала с полным контекстом.

Ключевое: результат — файл на диске, а не текст в чате. Транскрипт теряется, файл нет.

## Использование

```
/handoff <тема>
```

Например: `/handoff bug-7558`, `/handoff nightly-triage`, `/handoff rms-phase3`.

Если тема не указана — вывести её из текущей работы (номер бага, имя ветки, модуль).

---

## Куда пишем

```
.swap/sl/handoff/<YYYY-MM-DD>-<тема>.md
```

- Директория уже в `.gitignore` — **никогда не коммитить**.
- Дату брать командой, не из головы:
  ```bash
  date +%F
  ```
- Если файл на эту дату и тему уже есть — **дописать новую секцию с временной меткой**,
  а не перезаписать. История отката гипотез важна.
- Создать директорию, если её нет: `mkdir -p .swap/sl/handoff`.

---

## Что собрать перед записью

Не сочинять — собрать фактами:

```bash
git rev-parse --show-toplevel          # путь worktree
git branch --show-current              # ветка
git status --short                     # незакоммиченное
git log --oneline origin/develop..HEAD # коммиты ветки
git ls-remote origin "$(git branch --show-current)"  # запушено или нет
```

Если ветка не запушена или локальный SHA расходится с remote — **написать это явно**,
это первое, что должна знать новая сессия.

Ссылки на MR — из `git log` (GitLab пишет URL в вывод push) или из существующего файла
ремарок, если работал `/get-comment`.

## Требования к содержанию

**Секция «Отвергнутые гипотезы» — обязательна и не пропускается.** Это главная ценность
документа: без неё новая сессия пойдёт по тем же тупикам. Если гипотез не отвергали —
написать «нет», а не удалять секцию.

**Секция «Сделано» — только с SHA.** «Поправил маппер» без коммита — это не сделано,
это незакоммиченное изменение, ему место в «Состояние».

**Промпт для новой сессии** — самодостаточный: включает номер бага/тикета, путь к этому
же handoff-файлу и первый конкретный шаг. Проверка: если вставить его в чистую сессию,
она не должна задавать уточняющих вопросов о том, что вообще происходит.

**Язык — русский** (правило проекта), команды и идентификаторы — английский.

## После записи

Вывести пользователю:

```
Handoff записан: .swap/sl/handoff/<файл>
Ветка: <имя> (<запушена / НЕ запушена>)
Остаток: <N> пунктов
```

и **сам промпт для новой сессии** отдельным блоком — чтобы его можно было скопировать
сразу, не открывая файл.

---

## Заметки

- Скилл ничего не коммитит, не пушит и не меняет код — только читает состояние и пишет файл.
- Не путать с `/mr`: тот описывает изменения для ревьюера, этот — состояние для себя.
- Связанные скиллы: `/bugfix` (вызывает `/handoff` при блокировке), `/pre-mr`.
