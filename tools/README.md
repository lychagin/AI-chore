# Утилиты

Самостоятельные программы, а не артефакты Claude Code: MCP-серверы, генератор описания
MR, сборщик ремарок, конвертеры. `install.sh` их **не** раскладывает — у каждой свой
способ подключения (`npm install`, регистрация MCP-сервера, бит выполнения), описанный
в её собственном README.

---

## Статус

Каталог пока пуст: утилиты переносятся отдельным заходом. Планируется:

| Утилита | Что делает | Кто на неё опирается |
| --- | --- | --- |
| `mr-template` | Считает контекст ветки, тянет данные тикета и собирает описание MR по адаптивному шаблону | [`/mr`](../commands/mr.md) |
| `review-collector` | Выгружает комментарии MR и готовит их к анализу | [`mine-patterns`](../skills/mine-patterns/SKILL.md), [`review-commits`](../skills/review-commits/SKILL.md) |
| `mr-monitor` | Следит за состоянием MR: перебазирование под агентом, статус пайплайна | — |
| `mcp-servers/mcp-gitlab` | MCP-сервер GitLab: ремарки, MR, issues, пайплайны | [`get-comment`](../skills/get-comment/SKILL.md), [`resolve-remarks`](../skills/resolve-remarks/SKILL.md) |
| `mcp-servers/mcp-openproject` | MCP-сервер трекера: тикеты, комментарии, вложения, списание времени | скиллы работы с багами |
| `mcp-servers/mcp-dgraph-server` | MCP-сервер к базе: запросы, статистика, мутации | — |
| `eml-to-md` | Конвертер писем в markdown | разбор переписки с заказчиком |
| `md2pdf` | Markdown → PDF | выпуск документов |
| `docker-tools` | Обвязка над docker для локальных стендов | — |
| `nightly` | Разбор результатов ночного прогона тестов | — |

Справочник по MCP-инструментам и порядку их подключения уже перенесён:
[`../docs/mcp-tools.md`](../docs/mcp-tools.md).
