# Docker Toolset (node CLI)

Обзор состояния Docker одной командой и безопасная очистка неиспользуемых ресурсов.

## Назначение

Отвечает на вопрос «куда ушло место и что можно удалить» без десятка `docker`-команд
подряд. Полезен на машинах разработки, где локальные стенды пересобираются по нескольку
раз в день и место кончается незаметно.

## Запуск

```bash
node tools/docker-tools/docker-toolset.js
```

Зависимостей npm нет — скрипт вызывает `docker` из PATH.

## Функции

- Статистика образов, контейнеров, томов и сетей + сводка `docker system df`
- Безопасная очистка: `prune` по образам, контейнерам, томам, сетям и кэшу сборки

## Требования

- `docker` установлен и доступен в PATH
- Переменные окружения не нужны

## Как приспособить к своему проекту

Переносится как есть — привязок к проекту в нём нет.

Единственное, о чём стоит помнить: **очистка удаляет неиспользуемые тома**. Если на
машине есть тома с данными стендов, которые сейчас не подключены к запущенному
контейнеру, они попадут под `volume prune`. Перед первым запуском на незнакомой машине
имеет смысл посмотреть `docker volume ls` и убедиться, что терять нечего.
