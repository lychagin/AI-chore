description: Генерировать диаграммы из сущностей и юз кейсов

---

Ты помощник аналитика. Создай визуальные диаграммы на основе артефактов проекта.

**Твоя задача:**

1. Спроси пользователя какие диаграммы нужны:
   - **ER-диаграмма** (Entity-Relationship) - связи между сущностями
   - **Диаграмма Use Case** - акторы и юз кейсы
   - **Диаграмма последовательности** - для конкретного юз кейса
   - **Диаграмма классов** - структура сущностей с атрибутами
   - **Все диаграммы** - создать все типы

2. Собери данные из проекта:
   - Все сущности из `entities/`
   - Все юз кейсы из `use-cases/`
   - Связи между ними
   - Атрибуты сущностей

3. Создай диаграммы в формате Mermaid:

   ### A. ER-диаграмма (связи сущностей)

   ```mermaid
   erDiagram
       ENTITY-1 ||--o{ ENTITY-2 : "has many"
       ENTITY-1 {
           uuid id PK
           string name
           datetime created_at
       }
       ENTITY-2 {
           uuid id PK
           uuid entity1_id FK
           string title
       }
   ```

   ### B. Use Case диаграмма

   ```mermaid
   graph TB
       Actor1[Пользователь]
       Actor2[Администратор]

       UC1[UC-001: Регистрация]
       UC2[UC-002: Вход]
       UC3[UC-003: Управление]

       Actor1 --> UC1
       Actor1 --> UC2
       Actor2 --> UC3
   ```

   ### C. Диаграмма последовательности

   ```mermaid
   sequenceDiagram
       participant User as Пользователь
       participant UI as Интерфейс
       participant API as API
       participant DB as База данных

       User->>UI: Вводит данные регистрации
       UI->>API: POST /register
       API->>DB: Проверка уникальности email
       DB-->>API: Email свободен
       API->>DB: Создание пользователя
       DB-->>API: Пользователь создан
       API-->>UI: Успех
       UI-->>User: Показать подтверждение
   ```

   ### D. Диаграмма классов

   ```mermaid
   classDiagram
       class User {
           +UUID id
           +String email
           +String name
           +String surname
           +DateTime created_at
           +Boolean active
           +register()
           +login()
           +deactivate()
       }

       class Order {
           +UUID id
           +UUID user_id
           +Decimal total
           +DateTime created_at
           +create()
           +cancel()
       }

       User "1" --> "0..*" Order : has
   ```

4. Для каждой диаграммы:
   - Создай файл в `analysis/diagrams/`
   - Название: `diagram-{тип}-YYYY-MM-DD.md`
   - Добавь описание что показывает диаграмма
   - Включи Mermaid код
   - Добавь легенду если нужно

5. Создай индексный файл `analysis/diagrams/README.md` со списком всех диаграмм

6. **ВАЖНО: Создай PNG изображения из Mermaid диаграмм:**

   После создания всех .md файлов с диаграммами, используй `@mermaid-js/mermaid-cli` для генерации PNG изображений.

   **Шаги:**

   a. Для каждого созданного файла диаграммы (`diagram-*.md`):
   - Извлеки Mermaid код из markdown (блок между `mermaid и `)
   - Сохрани в временный файл `.mmd`

   b. Используй `npx` для генерации PNG (без глобальной установки):

   ```bash
   npx -p @mermaid-js/mermaid-cli mmdc -i diagram-er.mmd -o diagram-er-2025-11-11.png -b transparent
   ```

   c. Параметры команды:
   - `-i` - входной файл (.mmd с кодом Mermaid)
   - `-o` - выходной файл (.png)
   - `-b transparent` - прозрачный фон (опционально)
   - `-w 1920` - ширина изображения (опционально, по умолчанию 800)
   - `-H 1080` - высота изображения (опционально)

   d. Сохрани PNG файлы в ту же папку `analysis/diagrams/`:
   - `diagram-er-2025-11-11.png`
   - `diagram-use-case-2025-11-11.png`
   - `diagram-sequence-uc002-2025-11-11.png`
   - `diagram-class-2025-11-11.png`

   e. Обнови README.md, добавив ссылки на PNG изображения:

   ```markdown
   ### 1. ER-диаграмма

   📄 Markdown: [diagram-er-2025-11-11.md](diagram-er-2025-11-11.md)
   🖼️ Изображение: [diagram-er-2025-11-11.png](diagram-er-2025-11-11.png)
   ```

   **Обработка ошибок:**
   - Если `npx` команда не работает, сообщи пользователю и продолжи без PNG
   - Если отдельная диаграмма не конвертируется (слишком большая/сложная), сообщи об этом
   - Логируй ошибки в отчет генерации

   **Примечание:** Первый запуск `npx @mermaid-js/mermaid-cli` может занять ~30-60 секунд для скачивания пакета.

7. Полезные обозначения для связей:

   **ER-диаграмма:**
   - `||--||` : Один к одному
   - `||--o{` : Один ко многим
   - `}o--o{` : Многие ко многим
   - `||--o|` : Один к нулю или одному

   **Типы связей:**
   - `has` - имеет
   - `belongs to` - принадлежит
   - `uses` - использует
   - `creates` - создает
