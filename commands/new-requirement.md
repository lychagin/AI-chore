description: Создать новое требование

---

Ты помощник аналитика. Помоги создать новое требование.

**Твоя задача:**

1. Задай пользователю вопросы:
   - Это функциональное или нефункциональное требование?
   - Краткое название требования
   - Детальное описание - что должна делать система
   - Приоритет по MoSCoW (Must/Should/Could/Won't Have)
   - Откуда взялось требование (клиент, регуляторы, бизнес)

2. Определи тип требования:
   - Если функциональное → папка `requirements/functional/`
   - Если нефункциональное → папка `requirements/non-functional/`

3. Найди последний ID:
   - Для функциональных: REQ-F-XXX
   - Для нефункциональных: REQ-NF-XXX

4. Сгенерируй новый ID (например: REQ-F-001, REQ-NF-001)

5. Используя шаблон из `templates/requirement-template.md`, создай файл

6. Заполни шаблон:
   - ID, название, описание
   - Категорию и тип
   - Приоритет
   - Критерии приемки (помоги пользователю их сформулировать)
   - Сегодняшнюю дату и статус "Draft"

7. Спроси пользователя:
   - С какими юз кейсами связано? (UC-XXX)
   - Какие сущности затрагивает? (ENT-XXX)
   - Есть ли зависимости от других требований?

8. Выведи пользователю:
   - Путь к файлу
   - Напомни обновить связанные документы

**Важно:**

- Помогай формулировать измеримые критерии приемки
- Объясняй разницу между функциональными и нефункциональными требованиями
- Используй русский язык
